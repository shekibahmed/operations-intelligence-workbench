## Architectural decisions

- Reused `stableJson` rather than introducing a second equality mechanism, so
  Event matching has the same canonical JSON semantics already used for audit
  hashing and evidence-locator comparison.
- When multiple composable Observations share a constrained schema key, all
  must fall within the definition's accepted set. This prevents an Event from
  matching while its composed attributes also contain a value that violates
  the discriminator. The usual single-Observation path is unchanged.
- No new ADR is required. This task implements the already accepted ADR-010
  contract extension and remains pack-neutral.
