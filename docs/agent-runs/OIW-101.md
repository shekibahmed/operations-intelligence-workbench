## Architectural decisions
- `db/migrations/` is the single canonical migration location. It keeps
  generated SQL and Drizzle metadata independent of package build output.
- Canonical many-to-many relationships use scoped link tables rather than
  opaque JSON arrays. Composite foreign keys include `workspace_id`, making
  isolation a database invariant as well as a repository convention.
- Observation revision snapshots are persistence-internal because contracts
  v1.1 do not define a correction record. This consumes the frozen Observation
  contract without modifying it and makes ADR-006 history inspectable.
- Audit immutability is enforced with a database trigger rather than relying
  on a host-specific pre-provisioned runtime role. The repository API still
  exposes no mutation path; future deployment-role provisioning can add
  least-privilege grants without changing the schema.
- Database timestamps are hydrated as UTC ISO 8601 strings before contract
  validation because PostgreSQL's text representation uses a short UTC
  offset that the frozen timestamp schema does not accept.

No decision materially deviates from PRD §17.6, so no new ADR was required.

## Assumptions and deviations
- `Workspace` is the root of scope and therefore does not carry a self-
  referencing `workspace_id`; its repository has no unscoped list operation.
  Every other persisted table, including link/revision tables, carries scope.
- `MetricDefinition` is pack configuration and is not in the packet's explicit
  persisted-table list, so it is not stored as Workspace state in this task.
- The packet's local Postgres requirement is implemented with PostgreSQL 17
  Alpine. Hosted Supabase remains plain-Postgres compatible; no Supabase-only
  feature was added.
