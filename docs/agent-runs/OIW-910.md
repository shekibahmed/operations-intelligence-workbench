## Architectural decisions
- Motion is pure CSS inside a `no-preference` media query rather than relying on the global reduced-motion override,
  because the override shortens durations but not `animation-delay`, which would leave staggered elements hidden for
  about two seconds.
- Labels reveal without opacity so axe never samples low-contrast text mid-animation.
- `CountUp` mutates the digit span's text directly (no state), server-renders the final value, and keeps the final value in an
  `sr-only` span.
- Timings (10 s loop, 1.4 s intro) are mirrored between `PipelineHero.tsx` and the keyframes in `globals.css`.
