## Architectural decisions

- CI uses one Playwright worker. This avoids browser/build/database resource
  contention on shared runners and makes the persistence-backed suite stable.
  The observed job runtime is approximately 10m18s–12m16s, including setup and
  three repetitions, within the 30-minute timeout.
- CI builds once before `demo:seed`, because clean checkouts have no workspace
  package `dist/` outputs and the seed script consumes package exports. The
  Playwright web server then runs `next start` against that build; local runs
  retain the convenient build-and-start behavior.
- Signature tampering targets the first encoded signature character rather
  than the final character. A SHA-256 base64url signature has unused bits in
  its last character, so changing that character does not always change the
  decoded bytes.
- No ADR is required: this implements existing test/deployment policy and does
  not change product behavior, contracts, persistence, or package boundaries.
