## Architectural decisions

- The rules package stays pure and depends only on contracts. Application
  orchestration consumes its evaluator through a structural port; persistence
  executors remain in application. Batch C can replace executor registrations
  without changing rule evaluation.
- Related Event aggregates exclude the current Event, share at least one
  Entity, exclude future Events and use an inclusive historical window. Signal
  provenance adds the current Event plus all contributing related Events.
- Rule traces and deferred operational outcomes use append-only Audit Entries,
  avoiding a migration while preserving the exact rule/version, condition
  tree, facts, actions, rationale and idempotency key.
- Event matching never reads evaluation gold, Artifact-type conventions or raw
  pack files. It selects the first validated definition whose required reviewed
  Observations are present and whose required primary Entity is resolved.
  Missing mandatory inputs cause a safe audited abstention.
- Observation `entityType` is a matching hint only when an exact
  value/reference match exists. Otherwise ordinary operational facts retain
  their review state instead of being incorrectly routed to Entity review.
