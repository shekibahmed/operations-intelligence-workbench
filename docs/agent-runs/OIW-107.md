## Architectural decisions
- Partial in-Workspace reset preserves every prior Audit Entry and requires the
  caller to supply the reset Audit Entry. Clearing operational rows and
  appending that entry occur in one database transaction.
- Whole-Workspace deletion is the explicit ADR-007 lifecycle exception to
  append-only audit retention. PostgreSQL takes an exclusive `audit_entries`
  table lock while the append-only trigger is transactionally disabled, deletes
  the one Workspace through existing cascades, then re-enables it. Other
  sessions cannot observe the disabled window, and rollback restores the
  trigger on failure.
- Fixture-index schemas live in `@oiw/scenario-sdk`, which owns that file
  format. No shared canonical contract was needed, so contracts remain v1.1 and
  ADR-004 did not require an amendment.
- Fixture set names use the manifest's public values (`smoke`, `demo`,
  `edge-cases`); the SDK maps `edge-cases` to the manifest's `edgeCases` field.

## Assumptions and deviations
- `listExpired(before)` compares the contract's `expiresAt` TTL field.
  `resetAt` records when a reset occurred and is not treated as an expiry
  deadline despite the task packet's shorthand “reset_at/TTL expiry”.
- OIW-004b normalized physical payload directories to `artifacts/` but retained
  `content/` in fixture indexes. Because Scenario Packs are prohibited paths,
  the SDK resolves a missing declared `content/<file>` to
  `artifacts/<file>` and still verifies both checksums. This is documented and
  tested without changing pack content.
- Existing packs declare Artifact fixture records only; they do not declare
  pre-existing canonical Entities, Events or Cases. The loader returns every
  record they currently declare. OIW-105 can deterministically derive persisted
  UUID records from these stable fixture IDs.
- No task-packet or PRD deviation; no breaking change.

  privilege boundary.
- `loadFixtureSet` is explicit rather than eager during pack registry loading;
  OIW-105 chooses the requested fixture set and handles an invalid result.
