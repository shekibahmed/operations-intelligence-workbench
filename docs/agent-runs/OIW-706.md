## Architectural decisions
- The underscore rule is a registry enumeration convention, not a manifest or
  contract field. This keeps templates out of every registry consumer without
  changing frozen contracts.
- `validate:packs` consumes the registry's explicit skipped entries and invokes
  the existing single-pack loader for template validation. It does not add a
  registry option that could accidentally expose templates to application
  callers.
- The exported name predicate is shared by registry and validator so the
  convention cannot drift. No ADR is required for this bounded tooling rule.
