## Architectural decisions
- Serialization remains in `@oiw/application`; session, HTTP headers, rate limiting and Web Stream adaptation remain in the web boundary.
- Repository outputs are checked for `workspaceId` consistency in addition to repository query scoping, so an adapter regression fails closed.
- Audit exports sort chronologically (then by ID for ties) to retain visible chain order; Case records and every nested summary sort by stable ID.
- JSON preserves original text. CSV alone applies spreadsheet neutralisation because it is the spreadsheet-consumption boundary; quoting alone is explicitly not treated as protection.
- The Audit export appends its own `export` event before materialising records, making the downloaded chain accurately include the download action.

No ADR is required; these decisions implement FR-110 within the existing application/web and OIW-810 boundaries.
