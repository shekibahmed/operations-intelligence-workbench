## Architectural decisions

- Event definitions retain pack-authored `displayName`, `description` and
  required Observation semantics. Composed values remain keyed by schema key;
  no pack-specific attribute names enter core code.
- `occurredAt` always declares the `artifact-received-at` fallback. Definitions
  may map an Observation or explicitly map none. ADR-010 defines ISO date
  normalisation and invalid/missing-value fallback for the OIW-501 assembler.
- Primary Entity mapping names one composed Observation schema key or is null.
  SDK load rejects mappings to unknown schemas or schemas without an
  `entityType` hint.
- `seedEntities` is an optional manifest path, preserving compatibility for
  existing third-party/test manifests while allowing strict validation when
  present.
- Stable pack seed IDs become deterministic Workspace-scoped UUIDs. Aliases are
  persisted in the canonical field and mirrored into `attributes.aliases` for
  the documented exact/alias consumer boundary.
- No migration was added because the existing canonical Entity repository
  supports every required field.
