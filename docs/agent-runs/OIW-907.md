## Architectural decisions
- `PostgresTokenBucketStore` lives in `@oiw/persistence` and implements the
  `TokenBucketStore` port from `@oiw/application` (the dependency table
  already allows persistence → application ports). One atomic
  `INSERT … ON CONFLICT DO UPDATE` per consume: a data-modifying CTE is NOT
  safe here (CTE statements share one snapshot, so an outer UPDATE cannot
  see its sibling INSERT's row — verified empirically before settling on
  the upsert). `refilled_at_ms` is re-stamped on every consume to mirror
  the in-memory store's fractional-refill banking exactly.
- Store selection is an env switch at the composition root
  (`apps/web/src/lib/server/rate-limit.ts`); default `memory` keeps the
  single-instance demo unchanged, so no behavioural change ships by default.
- `output: "standalone"` is opt-in (`NEXT_OUTPUT=standalone` in the
  Dockerfile build stage): unconditional standalone breaks `next start`
  (Next 16 warns and misbehaves), and the documented local workflow must
  keep working.
- Vendoring Inter (OFL, licence committed beside the woff2) instead of
  `next/font/google` keeps builds reproducible offline and the demo
  network-free.
- All UI changes are in `apps/web` (product-experience track per A8);
  `packages/ui` untouched, so core pack-neutrality is unaffected.

## Known limitations / follow-up
- Next 16 + postgres.js: aborting in-flight renders (rapid navigation away
  from a mutating page) logs "destination stream closed early" and can
  stall subsequent DB-backed renders for a while on `next start`; both the
  pre-change baseline and this branch behave identically and the CI e2e
  suite (which always awaits) is unaffected. Worth an upstream-style
  investigation with a minimal repro if it ever shows up in real use.
- The docker `web` compose service is on the `full-demo` profile and needs
  `pnpm db:migrate` before first use; a first-run migrate automation was
  left to the owner's hosting task.
- Dark mode remains out of scope; the token layer is the natural starting
  point if wanted later.
