## Objective
A zero-setup public website at https://shekibahmed.github.io/operations-intelligence-workbench/ where a visitor understands OIW in under a minute (animated pipeline, trailer, walkthrough videos), reads the evidence casebook rendered (not as source), opts into background music, and finds agent entry points.

Parallel tasks: OIW-911 adds `apps/web/public/media/ambience.mp3` + `docs/media/CREDITS.md`; OIW-912 adds `llms.txt` (+ `apps/web/public/llms.txt`), `packages/mcp-server`, `.claude-plugin`; OIW-913 adds `docs/media/{hero.gif,poster-<pack>.jpg,<pack>-tour.vtt,trailer.vtt?}` and MP4s published as assets of GitHub release tag `media-latest` (`asset-reliability-tour.mp4`, `process-exceptions-tour.mp4`, `document-assurance-tour.mp4`, `trailer.mp4`). Build must succeed when any of these are missing (log what was skipped) and pick them up automatically once merged.

## Functional Requirements
1. `site/index.html` + `site/assets/site.css` + `site/assets/site.js` + `site/.nojekyll`. Sections: hero (one-line value: AI proposes, a person approves, the system enforces it; buttons: Try the live demo `<LIVE_DEMO_URL>` placeholder token resolved at build from env `LIVE_DEMO_URL` with fallback to the repo quick-start anchor, Watch the 25-second trailer, Read the casebook, GitHub repo); animated SVG/CSS nine-stage pipeline (Source, Artifact, Observation, Review, Event, Rule, Case and decision, Approval, Audit) with a travelling packet and per-stage one-line tooltips; "Walkthroughs" (`id="walkthroughs"`): trailer + three pack videos, each `<video controls preload="none" playsinline poster>` + `<track kind="captions" srclang="en" default>`; "Three scenarios" cards; "How the AI is kept honest" (evidence + confidence, review queue, deterministic rules, recorded approval, audit) with real screenshots copied from docs/screenshots; "For agents and builders" (llms.txt, MCP server config snippet, plugin install commands, adversarial fixture corpus, pack authoring); background-music toggle `<button aria-pressed="false">Background music: off</button>` + `<audio preload="none" loop src="media/ambience.mp3">` with credit line and link to CREDITS, `<noscript>` native-controls fallback; footer (MIT, Kaamchor link, contact). OG/Twitter meta tags with absolute Pages URLs and an `og:image` (use docs/screenshots/leadership-dashboard.png copied into the site until a social preview exists).
2. Motion: calm, transform/opacity only; full `prefers-reduced-motion: reduce` support (static complete diagram, no packet); no autoplay audio; videos never autoplay with sound. Respect WCAG AA contrast; keyboard reachable; visible focus; one h1; landmarks.
3. `scripts/site/build.ts` (tsx, typed under tsconfig.tools.json): assembles `_site/` from `site/**`; copies casebook HTML to `_site/casebook/` and asserts byte equality with source; copies `apps/web/public/media/*` → `_site/media/`, `docs/media/{*.vtt,*.jpg,*.gif,CREDITS.md}` → `_site/media/`, `docs/screenshots/*.png` → `_site/img/`, llms.txt → `_site/llms.txt`, raw markdown `AGENTS.md`, `docs/{ARCHITECTURE,DOMAIN_MODEL,PACK_AUTHORING,EVALUATION}.md` → `_site/docs/`; MP4s from `$SITE_MEDIA_DIR` → `_site/media/`; substitutes `LIVE_DEMO_URL`; hides (removes) video blocks whose MP4 is absent and logs it; fails on any root-absolute `href="/` or `src="/`; writes `_site/sitemap.xml` and `robots.txt`.
4. `.github/workflows/pages.yml`: on push to main (relevant paths), `workflow_dispatch`, and `release: [published]`; `permissions: contents: read, pages: write, id-token: write`; concurrency `pages`; checkout, pnpm/node setup as ci.yml, `pnpm install --frozen-lockfile`, `gh release download media-latest --dir .site-media --pattern '*.mp4' || echo no media release`, `SITE_MEDIA_DIR=.site-media LIVE_DEMO_URL=${{ vars.LIVE_DEMO_URL }} pnpm site:build`, `actions/configure-pages@v5`, `actions/upload-pages-artifact@v3` (path `_site`), `actions/deploy-pages@v4` in environment `github-pages`.
5. Root `package.json` script `site:build`; `.gitignore` entries.

## Non-Goals
Changing the Next app, a CMS, analytics trackers or third-party scripts/fonts (self-contained; system font stack or vendored Inter copied from apps/web/src/app/fonts if licence file present).

## Acceptance Criteria
1. `pnpm site:build` succeeds with and without optional media present; `_site` serves correctly under a sub-path (test with a local static server mounted at /operations-intelligence-workbench/).
2. axe-core (via @axe-core/playwright from apps/web) reports no violations on the built index at desktop and 390px; reduced-motion screenshot shows complete static diagram.
3. Lighthouse-style sanity: no external requests except the GitHub/live-demo links; total page weight excluding videos < 1.5 MB.
