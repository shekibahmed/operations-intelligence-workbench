## Functional Requirements
1. Compose: `docker compose up -d` and `docker compose up -d postgres` work with no `.env`; the `web` service still cannot start without a real SESSION_SECRET (the app already refuses in production — verify in session.ts; keep or move the guard so no insecure default secret exists). Verify by running compose in a temp copy with no `.env`.
2. `render.yaml` blueprint: one free Docker web service from `./Dockerfile`, `autoDeployTrigger: "off"` (current spelling of the deprecated `autoDeploy: false`), health check on a DB-free route, env: `DATABASE_URL` (sync:false; Neon direct URI, `sslmode=require`), `SESSION_SECRET` and `OIW_RATE_LIMIT_IP_SALT` (generateValue), `OIW_TRUSTED_PROXY_HEADER=x-forwarded-for` (confirm Render's header semantics against SECURITY.md §3.9 and document the residual), `OIW_RATE_LIMIT_STORE=postgres`, `DATABASE_POOL_MAX=3`, `OIW_ASSESSMENT_SINK=postgres`, `NEXT_PUBLIC_SITE_URL`. Check whether Render passes env to Docker build (HSTS in next.config is build-time) and document.
3. `deploy.yml`: `workflow_run` after CI success on main + `workflow_dispatch`; skip cleanly (notice, success) when secrets are absent; `pnpm install --frozen-lockfile`, `pnpm db:migrate` with `secrets.DATABASE_URL`, then POST `secrets.RENDER_DEPLOY_HOOK_URL`; `permissions: contents: read`; concurrency group.
4. `keepalive.yml`: every 10 min 06:00–22:00 UTC + dispatch; GET `${{ vars.RENDER_APP_URL }}/` with retries (not `/robots.txt`: a spun-down Render free service answers that itself without waking the app), last run 21:50 UTC; no-op when the variable is unset; comments on Render free sleep (15 min), 750 h/month, GitHub 60-day schedule pause, Neon autosuspend.
5. `expire-demo.yml`: restore hourly schedule but skip cleanly when `DATABASE_URL` secret is absent (the previous failure mode).
6. `docs/DEPLOYMENT.md`: new section "Render free tier + Neon (public demo)" with exact owner steps (Neon project/region, direct URL, Render Blueprint, deploy hook, GitHub secrets `DATABASE_URL`, `RENDER_DEPLOY_HOOK_URL`, variable `RENDER_APP_URL`, first `gh workflow run deploy.yml`, smoke checks), cold-start expectations, and cost (free). `.dockerignore` additions: `site`, `_site`, `plugins`, `.claude-plugin`, `render.yaml`, `.mcp.json`, `docs/media/*.mp4`, `docs/media/*.webm`.
7. Validate workflows with `actionlint` if available (`go run`/binary) or at least YAML parse; validate render.yaml against Render's blueprint schema if obtainable.
