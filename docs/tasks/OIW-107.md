# Task OIW-107: Persistence and Scenario-SDK API Extensions for Seed/Reset

## Owner
Codex (high reasoning)

## Branch
`agent/codex/OIW-107-seed-reset-apis`

## Worktree
`../oiw-core`

## Objective
Add the bounded public APIs that OIW-105 is BLOCKED on (see
`docs/agent-runs/OIW-105.md`, "Known limitations / follow-up"): repository
operations for workspace lookup/expiry/reset in `@oiw/persistence`, and a
typed fixture-set loader in `@oiw/scenario-sdk`. Nothing else.

## Background
OIW-105 correctly stopped rather than bypass package boundaries. This task
is the owning-track response. This packet explicitly grants ownership of
both packages for these additions, and authorizes an ADDITIVE contract
change (seed-bundle / fixture-set runtime schema in `@oiw/contracts`) if —
and only if — the loader needs it; document it as contracts v1.2 in the
agent-run and extend ADR-004 accordingly.

## Functional Requirements
1. Persistence workspace repository additions: `findBySlug(slug)`;
   enumerate workspaces with `reset_at`/TTL expiry before a given time;
   delete a workspace and all its scoped records FK-safely; an atomic
   workspace-scoped clear/reset primitive (or transaction-capable unit of
   work) that removes derived records while honouring the audit append-only
   rule (document the chosen audit semantics for reset — deleting a whole
   guest workspace including its audit rows is permitted per ADR-007;
   partial in-workspace resets must write an audit entry).
2. Scenario-SDK: `loadFixtureSet(pack, setName)` returning typed,
   schema-validated seedable records + artifact content with deterministic
   ordering; SDK owns paths/parsing/validation; tolerant of packs without
   fixtures (typed empty result + warning), consistent with OIW-103
   behaviour.
3. Tests: all existing tests keep passing unmodified; new tests for each
   added operation including cross-workspace-safety of delete/reset (verify
   workspace B untouched) and fixture-set loader validation failures.

## Non-Goals
No seed/reset services themselves (OIW-105). No CLI. No pack content.
