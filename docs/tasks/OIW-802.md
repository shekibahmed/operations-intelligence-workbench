# Task OIW-802: Evaluation Runner (pnpm eval)

## Owner
Codex (high reasoning)

## Branch
`agent/codex/OIW-802-eval-runner`

## Worktree
`../oiw-core`

## Objective
Replace the `pnpm eval` stub with the real evaluation runner defined in
`docs/EVALUATION.md`: score every pack's gold sets across the PRD §21.3
metric dimensions and report per-pack, per-dimension results with a
non-zero exit on regression. First Wave 4 task (A8: runner is core-track;
evaluation design already exists from OIW-005).

## Background
Gold sets exist and are exercised binarily by the common lifecycle test.
The runner adds graded measurement: precision/recall per field, evidence-
span correctness, abstention correctness, entity/rule/approval/case
correctness, duplicate prevention — per PRD §21.3 and docs/EVALUATION.md
(read its metric definitions and any tolerances it specifies; it is the
spec, written before implementation — where it conflicts with merged
reality, follow reality and note the delta).

## Functional Requirements
1. Runner pipeline per pack: fresh workspace → seed → process+advance the
   gold-covered fixture sets via public services → compare against
   `evaluations/` gold across dimensions: field extraction precision/
   recall, classification accuracy, evidence-span correctness, entity-
   resolution accuracy, abstention correctness (incl. negated), rule-
   execution correctness, approval-policy correctness, duplicate-event
   prevention, case-state correctness (§21.3).
2. Output: human-readable table + machine-readable JSON
   (`eval-results.json`, gitignored); per-pack and aggregate scores;
   explicit per-dimension thresholds (default 1.0 for deterministic
   fixture mode — any miss lists the offending fixture/field verbatim);
   non-zero exit under threshold.
3. CLI flags per PRD §21.4; runs against docker Postgres like the
   integration tests.
4. CI: eval step added to the quality workflow.
5. Tests: runner unit tests with a deliberately-broken synthetic gold
   fixture proving each dimension can fail; full run green on all three
   real packs.

- `pnpm lint && typecheck && test && build && architecture:check` pass;
  CI green including the new eval step.
