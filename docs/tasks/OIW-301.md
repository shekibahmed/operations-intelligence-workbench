## Functional Requirements
1. Ingestion service: accept a raw input (text/CSV/JSON/PDF-text) for a
   workspace+source, store an immutable Artifact with checksum, create
   ArtifactSegments per adapter, set processing states
   (`received → processed | failed | needs-review`), audit entries
   throughout. Exact-duplicate detection by checksum → link + flag, never
   double-ingest (near-duplicates deferred per ADR-008).
2. Adapters: plain text (message; segment per message for multi-message
   chat logs using text-range locators), CSV (row → artifact or row
   segments per pack config; table-cell locators), JSON (json-path
   locators), PDF-fixture (parse `--- page N ---` markers from raw text →
   page locators; real binary PDF parsing deferred with the A7 note).
3. FixtureIntelligenceProvider: implements `IntelligenceProvider.extract`
   by checksum lookup of the pack's expected-extraction files (via
   scenario-sdk); fails loudly on a missing checksum; `deterministic: true`
   metadata; processing trace populated.
4. Structured-output validation: provider results validated against the
   active pack's observation schemas; invalid output → rejected + routed to
   review, never persisted as accepted truth (FR-022).
5. Abstention/confidence policy: per-schema confidence threshold (pack
   configurable, sensible default): below threshold or
   `insufficient-evidence`/`negated`-with-low-confidence → Observation
   persisted with `reviewStatus: "pending"`; above → `"not-required"`.
   `alternativeCandidates` preserved. Injection-text artifacts are data:
   extraction only, provably no behavioural effect (test with the pack's
   edge-006 injection artifact).
6. End-to-end processing service: `processArtifact(workspaceId, artifactId)`
   runs adapter → provider → validation → persistence → audit, synchronous
   (A7), idempotent per artifact (reprocessing does not duplicate
   observations).

## Acceptance Criteria
- Integration test: ingest + process every asset-reliability smoke fixture;
  persisted proposed observations match the pack's expected extractions
  (values, evidence locators, confidence, status) exactly.
- Edge-case tests: insufficient-evidence → pending review; negated
  persisted as negated; ambiguous (edge-003) carries alternativeCandidates;
  duplicate (edge-005) flagged not re-ingested; injection (edge-006) inert.
- `pnpm lint && typecheck && test && build && architecture:check` pass;
  CI green.
