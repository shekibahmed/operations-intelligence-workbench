   guess); definitions failing their value constraints are excluded even if
   their `requiredObservations` are present.
2. Deterministic selection order preserved; safe audited abstention when no
   definition matches remains intact.
3. Regression: full existing suite passes UNMODIFIED — especially
   asset-reliability 9/9 smoke parity and the A-142 storyline tests.
4. New unit tests: value-discriminated pair selects correctly both ways;
   constraint-failing candidate excluded; missing discriminator observation
   → no match/abstention. Use document-assurance's real
   `reviewer-signoff-recorded` vs `clarification-requested` shapes as one
   fixture.
