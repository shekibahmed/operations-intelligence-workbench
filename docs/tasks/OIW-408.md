## Functional Requirements
1. Link entity: on a pending/conflicting observation, open an accessible
   picker listing the workspace's entities (searchable by display name /
   external reference; shows entity type label from pack labels); linking
   sets the observation's entity, records reviewer + timestamp + audit
   entry; works both for candidate cases (existing UI intact) and free
   linking.
2. Create entity: inline form (entity type from pack entity types, display
   name, external reference); creates the entity workspace-scoped, links
   the observation, audits both; validation errors accessible.
3. Add reviewer note: free-text note on an observation persisted as an
   append-only audit entry (actor = guest session identity, timestamp);
   notes visible in the observation's history panel and the audit explorer.
4. All server actions session-validated (ADR-007 pattern already in the
   codebase); keyboard + focus management per §16.3; empty/error states.
5. Tests: component tests for the three actions; extend the Playwright
   review journey with link-entity and note steps.
