# Task OIW-109: Event-Definition Contract (v1.3), Seed Entity Catalogue and SDK/Seed Wiring

## Owner
Codex (high reasoning)

## Branch
`agent/codex/OIW-109-event-defs-seed-entities`

## Worktree
`../oiw-core`

## Objective
Close the three upstream gaps blocking OIW-501 (authoritative list:
`docs/agent-runs/OIW-501.md`): (1) a runtime contract + SDK catalogue for
pack event definitions including observation→event mapping and Event time
mapping; (2) a seed-entity catalogue format + authored seed entities for
all three packs; (3) seed-service and SDK wiring so seeded workspaces
contain Entities. Nothing else.

## Background
Same pattern as OIW-108 (observation schemas): pack `schemas/events/*` files
exist but have no runtime contract and are discarded at load. Packs have no
entity seed data — narrative/entities.md describes entities (A-142 etc.)
but nothing machine-readable is seeded. This packet grants cross-path
authority for exactly these changes. Contract changes are v1.3 (additive).

## Functional Requirements
1. `EventDefinitionSchema` (contracts v1.3): eventType id + label; which
   observation schemaKeys compose the event (required/optional);
   **occurredAt mapping** (which observation supplies the Event time, with
   fallback to artifact receivedAt); entity-linking (which observation
   supplies the primary entity reference). Fit to what the packs shipped;
   normalise pack files mechanically where needed.
2. `SeedEntitySchema` (contracts v1.3): id (stable slug), entityType,
   displayName, externalReference, attributes (validated JSON incl.
   optional `aliases: string[]`), status. Manifest gains an additive
   `seedEntities` path field if that is the cleanest reference mechanism.
3. SDK: `LoadedScenarioPack.eventDefinitions` typed catalogue (validated,
   duplicate-checked, observation schemaKeys cross-checked against the
   observation catalogue); public access to validated seed entities;
   `validate:packs` enforces both; all three real packs pass.
4. Seed entities authored for all three packs from narrative/entities.md —
   asset-reliability complete (assets incl. A-142 and near-miss A-140 with
   aliases as described in the ambiguity narrative, components, locations,
   service providers); other packs enough to support their storylines.
5. Seed service inserts seed entities at seed and reset; determinism test
   (identical entity rows across two seeds) and isolation test extended;
   `demo:seed` output reports entity count.
6. ADR-010 records both contract shapes and the occurredAt mapping design.
