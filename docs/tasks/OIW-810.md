# Task OIW-810: Security Hardening for Public Demonstration

## Owner
Codex (high reasoning)

## Objective
Close the public-deployment security gates in `docs/SECURITY.md` that are
still open: rate limiting on guest-writable endpoints, upload/input
restrictions for manual artifact creation, workspace TTL expiry cleanup
wiring, and product-level (HTTP/server-action layer) adversarial tests for
workspace isolation and approval bypass. Combines PRD OIW-806/807/810 and
the rate-limiting item deferred from OIW-210.

## Functional Requirements
1. Rate limiting (PRD §16.4, SECURITY §3 DoS): guest workspace creation,
   artifact processing, review actions, decision actions, reset —
   limited per session AND per IP with sane defaults (configurable via
   env); exceeding → 429-equivalent action result, audited once per
   window, no state change; documented limits.
2. Input restrictions: manual artifact creation (if exposed) and any
   upload path enforce allowed MIME/types and size caps; untrusted content
   never interpreted (regression test for the injection fixture at the
   HTTP layer).
3. Expiry: wire the existing expired-workspace enumeration/deletion into a
   sweep entrypoint + CLI; test that expired guest workspaces (and only
   those) are removed with audit-safe semantics per ADR-007.
4. Adversarial product-level tests: cross-workspace access via URL
   tampering, forged/expired/tampered session cookies, direct object
   references across workspaces, approval bypass via crafted server-action
   inputs (status field manipulation, missing comment on high-risk,
   replayed approval), all must fail safely with generic errors.
5. SECURITY.md gate table updated with evidence (test names).

## Non-Goals
No auth/SSO (P2). No WAF/CDN config. No UI redesign. No Supabase RLS.

## Acceptance Criteria
- All adversarial tests fail-safe; rate limits provably enforced; expiry
  sweep tested.
- `pnpm lint && typecheck && test && build && eval && architecture:check`
  pass; e2e green (incl. new security specs); CI green.
