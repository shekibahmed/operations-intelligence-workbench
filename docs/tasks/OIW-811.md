# Task OIW-811: Case and Audit Export (FR-110)

## Owner
Codex (high reasoning)

## Branch
`agent/codex/OIW-811-exports`

## Worktree
`../oiw-core`

## Objective
Deliver FR-110 (deferred from P0 by amendment A7): CSV and JSON export of
cases and audit data for a synthetic demo workspace — server-side
generation, workspace-scoped, rate-limited, with a download entry point
in the UI.

## Inputs
- `AGENTS.md`, PRD FR-110/§9.15/§20.5, `docs/SECURITY.md` (export is a
  guest-writable/readable action: rate limit + no cross-workspace leak),
  `docs/UX_SPEC.md` (where export actions live on case list/detail and
  audit explorer), `packages/application/`, `apps/web/src/lib/server/`,
  OIW-810 rate-limit wiring pattern

## Owned Paths
- `packages/application/` (export service: cases + audit → JSON / CSV,
  deterministic column order, RFC 4180 CSV escaping, workspace-scoped)
- `apps/web/src/lib/server/` + a route handler for downloads +
  MINIMAL UI entry points (an "Export" button/menu on case list, case
  detail and audit explorer — reuse existing button components; no
  restyling)
- `tests/security/` export isolation + rate-limit tests
- `docs/agent-runs/OIW-811.md`; lockfile only if regeneration needed
  (prefer no new deps)

## Prohibited Paths
- `packages/contracts/`, engines, SDK, `scenario-packs/`, migrations,
  `SESSION.md`, `docs/tasks/`.

## Functional Requirements
1. Export service: `exportCases(workspaceId, format)` and
   `exportAudit(workspaceId, format)` (JSON + CSV); cases include related
   signals/actions/decisions/approvals summary columns; audit entries
   export the append-only chain with hash fields; synthetic-data notice
   header row/field in every export (PRD §7.9/§14 disclaimer).
2. Download route: session-validated, workspace-scoped, rate-limited via
   the OIW-810 limiter, content-disposition with safe filenames, streamed
   for large sets, audited (`export` action per PRD §9.15).
3. UI: export controls per UX_SPEC placement; accessible names; works by
   keyboard; error state on limit/failure.
4. Tests: CSV escaping edge cases (commas, quotes, newlines, injection-
   like leading `=`/`+` cells neutralised for spreadsheet safety);
   cross-workspace export attempt rejected; rate limit enforced; e2e
   download assertion.

## Non-Goals
No PDF export. No scheduled exports. No exports of raw artifact binaries.

## Acceptance Criteria
- Both formats for both datasets download correctly from the UI for a
  seeded+advanced workspace; spreadsheet-injection neutralised; isolation
  + rate-limit tests pass; `pnpm lint && typecheck && test && build &&
  eval && architecture:check` pass; e2e green; CI green.

## Required Commands
`docker compose up -d && pnpm db:migrate && pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm eval && pnpm architecture:check && (cd apps/web && pnpm test:e2e)`
