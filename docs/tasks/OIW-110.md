# Task OIW-110: Event-Definition Reconciliation and Ambiguity Validation

## Owner
Codex (high reasoning)

## Branch
`agent/codex/OIW-110-event-reconciliation`

## Worktree
`../oiw-core`

## Objective
Resolve the pack data defects blocking OIW-501 (authoritative evidence:
`docs/agent-runs/OIW-501.md`, "problems" section) so 9/9 Asset Reliability
smoke gold parity is achievable, and make this defect class impossible to
reintroduce by teaching `validate:packs` to reject indistinguishable event
definitions. Nothing else.

## Background
OIW-501's implementation is done and green; only pack data blocks it:
(1) smoke-004/005 extractions omit observation keys their gold
`maintenance-completed` events require; (2) `maintenance-completed` vs
`repair-scheduled` and `inspection-completed` vs `diagnostic-completed`
have identical required/optional/time/entity mappings, so no neutral engine
can choose between them (affects demo-011/demo-023 gold too).
`narrative/expected-outcomes.md` (read-only) is the semantic source of
truth for what each fixture SHOULD produce.

## Functional Requirements
1. For each ambiguous pair: make the definitions genuinely distinguishable,
   preferring real observation-key differences consistent with
   expected-outcomes.md semantics; only if no honest key distinction exists,
   add a minimal additive discriminator to EventDefinition (e.g. required
   observation value predicate) and author it.
2. Reconcile smoke-004/005 (and any similarly affected demo fixtures incl.
   demo-011/demo-023): align event-definition required keys, extraction
   files and gold expectations with the narrative semantics — change the
   MINIMUM set; document each change and its narrative justification.
3. Validator: `validate:packs` fails when two event definitions in a pack
   cannot be distinguished by any input the engine may use; run it across
   ALL THREE packs and fix any hits in the other packs' event definitions
   the same way (extraction/gold fixes outside asset-reliability only if a
   hit forces them — document).
4. Keep every existing suite green; artifact checksums unchanged
   (verify: `git diff --name-only` contains no `fixtures/**/artifacts/`).

## Non-Goals

- A dry-run note in the agent-run showing why 9/9 parity is now achievable
  for OIW-501 (map each of smoke-004/005/demo-011/demo-023 to its now-
  unambiguous definition and satisfied required keys).
