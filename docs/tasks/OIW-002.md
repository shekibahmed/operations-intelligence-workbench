## Functional Requirements
1. **Negated findings:** add a third variant to `ProposedObservationSchema`
   with `status: "negated"` — the source explicitly denies/rules out the
   fact (distinct from `insufficient-evidence`). Requires evidence (min 1),
   confidence, and a `reason`. Mirror on the domain `Observation` so a
   persisted observation can record confirmed-absent
   (suggestion: `evidenceStatus` gains `"negated"`; keep the
   supported-requires-segment refinement intact).
2. **Alternative candidates:** add optional
   `alternativeCandidates: z.array({ value: JsonValue, confidence: 0..1 })`
   (default absent/empty) to the `extracted` variant and to the domain
   `Observation`, for ambiguous extractions per PRD §13.5.
3. **Conflicting review state:** add `"conflicting"` to the domain
   `Observation.reviewStatus` enum, for two live contradictory observations
   about the same entity that a human must resolve.
4. Update/extend unit tests for all three (valid + invalid cases; e.g.
   negated without evidence fails; candidate confidence out of range fails).
5. Write ADR-008 recording the three changes and why near-duplicate
   handling and source-quality flags were deliberately NOT added (deferred
   to Wave 1 engine design — see agent-run items 3 and 6).
6. Update `docs/DOMAIN_MODEL.md` accordingly.
