# Task OIW-911: Opt-in ambient music for the casebook (CC0 / public domain)

## Owner
Claude Code lead (Opus orchestrator) with a Sonnet implementation worker.

## Branch
`agent/claude/OIW-911-ambience-audio`

## Worktree
Isolated sibling worktree; location recorded in the lead session only.

## Objective
Ship one verifiably public-domain or CC0 music recording, credited, and offer it as an off-by-default, script-free player in the evidence casebook. The same file is later baked into walkthrough videos (OIW-913) and the Pages landing (OIW-915).

## Background
Traction sprint 2026-10-18. Owner asked for public-domain/open-source background music. Autoplay is excluded (browsers block it; accessibility). The casebook is byte-locked by `pnpm casebook:check` and its tests forbid script/button/img/iframe/form/link-stylesheet/`url(` and any non-navigation request while reading.

## Functional Requirements
1. Source ONE calm instrumental recording whose *recording* (not only composition) is public domain or CC0 1.0, verified from machine-readable licence metadata. Preferred: Wikimedia Commons file whose `extmetadata.LicenseShortName` is "Public domain" or "CC0" (e.g. a Musopen recording of Satie's Gymnopédie No. 1 or similar calm piano), checked via `https://commons.wikimedia.org/w/api.php?action=query&titles=File:<name>&prop=imageinfo&iiprop=url|extmetadata&format=json`. Acceptable: OpenGameArt entry labelled CC0. Rejected: CC BY (incl. Kevin MacLeod), NC, Pixabay licence, anything ambiguous.
2. Download into a fresh empty directory under the session scratchpad; never execute anything from it. Encode with ffmpeg to `apps/web/public/media/ambience.mp3`: 60–120 s excerpt, mono or stereo 96 kbps, `loudnorm` to about -20 LUFS, 2 s fade-in and 3 s fade-out, ≤ 1.5 MB.
3. `docs/media/CREDITS.md`: title, composer, performer, source page URL, licence name + URL, the API evidence (quoted licence field), SHA-256 of the committed file, edits made, where it is used (casebook, Pages landing, walkthrough videos).
4. Casebook template: after `</main>` and before `<footer>`, an `<aside>` containing `<details><summary>Optional background music (off)</summary>` with one sentence ("Nothing loads or plays until you press play; the casebook is complete without it."), `<audio controls preload="none" loop src="../media/ambience.mp3"></audio>`, and plain-text credit. No `autoplay`, no script, no button element, no link. ~6 CSS rules in the inline stylesheet. Then `pnpm casebook:build` and commit the regenerated HTML.
5. Tests: casebook.test.ts asserts one `<audio`, `preload="none"`, no `autoplay`; casebook.spec.ts asserts audio count 1 and preload none, and the existing zero-request and keyboard-order assertions still pass. If Chromium issues any request for the audio while reading, remove `src` from the casebook audio and document the fallback (player lives only on the Pages landing).
6. Pack casebook README: one sentence that the music is presentation, not recorded evidence.

## Non-Goals
Autoplay, persistence of preference, pages other than the casebook, video encoding.

## Acceptance Criteria
1. Licence evidence is machine-verifiable and quoted in CREDITS.md.
2. `pnpm casebook:check` clean after regeneration; `pnpm --filter @oiw/web test:casebook` green (JS disabled) and `CASEBOOK_HTTP=1` variant green.
3. Reading the casebook makes zero network requests until play is pressed.
