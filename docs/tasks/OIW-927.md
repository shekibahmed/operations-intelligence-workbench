## Acceptance Criteria

- A provider implements `IntelligenceProvider.extract` against any
  OpenAI-compatible chat endpoint, configured only from `OIW_LLM_*`.
- The provider computes evidence locators from verbatim quotes and withholds
  any ungrounded value as insufficient-evidence with confidence 0.
- No new dependency and no lockfile change. The demo, the app and `pnpm eval`
  still use the fixture provider.
- `pnpm eval:llm` scores a model against the gold sets with no database.
- All quality gates pass.

## Required Tests

Unit tests with an injected `fetch`: grounding, ungrounded withholding,
unknown schema keys, confidence clamping, untrusted delimiters, the key sent
only as a bearer header and absent from errors, HTTP retryability, no call
without a text layer, environment configuration.
