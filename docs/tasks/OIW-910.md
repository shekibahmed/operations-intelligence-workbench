# Task OIW-910: Animated landing pipeline

## Owner
Claude Code lead (Opus orchestrator) with a Sonnet implementation worker; lead owns integration and merge.

## Objective
Make the public landing page (`/`) show, in motion, how one report travels from source to approved decision, without new dependencies and with reduced-motion honoured.

## Background
Traction sprint 2026-10-18 (lead plan). Visitors currently see a static page; short attention spans favour a moving explanation. PRD §16.3 accessibility and docs/UX_SPEC.md apply.

## Inputs
`apps/web/src/app/page.tsx`, `apps/web/src/app/globals.css` (tokens; reduced-motion block at line ~84), `apps/web/src/components/marketing/{icons.tsx,chrome.tsx}`, `apps/web/tests/routes.smoke.test.tsx`, `apps/web/e2e/{smoke,accessibility}.spec.ts`, `docs/UX_SPEC.md`, `docs/ux/00-landing.md`.

## Prohibited Paths
Lockfile, any `package.json`, packages/*, scenario-packs/*, README.md, SESSION.md, other routes.

## Functional Requirements
1. `PipelineHero` (server component): a nine-node pipeline (Source, Artifact, Observation, Review, Event, Rule, Case/Decision, Approval, Audit) rendered as `<figure>` + `<ol>`; nodes stagger in, connectors draw, a small "packet" travels along connectors. Pure CSS keyframes appended to `globals.css`; keyframe end state = fully revealed so the existing reduced-motion override leaves a complete static diagram. Neutral wording only (no pack terms).
2. `CountUp` client component (`"use client"`, <70 lines): SSR renders the final value; animates only if `IntersectionObserver` exists and reduced motion is not requested; animated digits `aria-hidden`, final value in an `sr-only` span.
3. `Stats` (server): four truthful figures — number of scenario packs (`stubPacks.length`), three lenses, nine pipeline stages, evaluation score 1.000 with a visible qualifier linking to docs/EVALUATION.md on GitHub (the score is on synthetic fixtures).
4. Scroll-reveal for existing "How it works" and capability cards via `@supports (animation-timeline: view())` only (static elsewhere).
5. Add a secondary link "Watch the 2-minute walkthrough" to `https://shekibahmed.github.io/operations-intelligence-workbench/#walkthroughs`. No `<video>` on this page (axe `video-caption`).
6. Keep: `h1` text, the casebook link `/casebook/a-142-repeat-fault.html`, `AnalyticsPageEvents`, section ids used by `chrome.tsx`.

## Non-Goals
New npm dependencies (no framer/motion/GSAP), audio, layout redesign, other routes.

## Acceptance Criteria
1. Animations run on a normal browser; with `prefers-reduced-motion: reduce` the page shows the complete static diagram with no motion.
2. axe (accessibility.spec) reports no violations on `/`; contrast uses existing ink tokens.
3. Unit + smoke tests remain green; new unit test covers CountUp's reduced-motion/no-IO paths and PipelineHero's nine nodes.
4. Desktop and mobile (390px) screenshots, both motion states, attached in the agent-run/PR.
